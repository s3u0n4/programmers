# 프로그래머스 - 충돌 위험 찾기

문제 핵심 매커니즘

목표:모든 로봇이 운송을 마칠 때까지 발생하는 '충돌 위험(같은 시간, 같은 좌표에 2대 이상)'의 총 횟수를 구하여라

이동 규칙: 1.세로(r)우선 이동:목표 지점과 세로 좌표가 다르면 세로로 먼저 한 칸 이동한다.

2.가로(c)후순 이동:세로 좌표가 같아지면 가로로 한 칸 이동한다.

3.시간 흐름:한 칸 이동할 때마다 1초가 소요된다.

가장 중요한 포인트는 '특정 시간에 로봇이 어디있는가?'를 전역적으로 기록하는 것입니다.

key 설정:t(시간),r(행),c(열)을 하나의 문자열로 묶어 Map의 키로 사용합니다.(예:"5,10,20"-> 5초에 10행 20열 위치)

value 설정:해당 키가 발생할 때마다 카운트를 증가시킵니다.

로봇들은 서로에게 영향을 주지 않고 각자의 경로를 따라갑니다.따라서 로봇 한 대씩 처음부터 끝까지 이동시키며 모든 기록을 globalLog에 남기면 됩니다.

-0초(시작점 처리):로봇이 움직이기 전 시작 위치도 반드시 기록해야 합니다.

경로 순회:routes배열에 담긴 목적지를 순서대로 방문하며 while문을 통해 한 칸씩 이동합니다.

Map활용: Object 보다 Map을 사용하면 수만 개의 기록이 쌓여도 데이터를 순회하거나 저장할 때의 성능 면에서 유리합니다.

충돌 판정 시점:모든 로봇의 시뮬레이션이 끝난 후,globalLog에 저장된 방문 횟수가 2 이상인 항목의 개수만 세면 됩니다.(3대가 모여도 '상황'은 1번으로 카운트한다는 조건 주의)

r,c이동 순서:문제에서 제시한 'r먼저,그 다음 c'순서를 while문의 순서로 정확히 구현해야 오차가 없습니다.

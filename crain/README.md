# 프로그래머스 - 지게차와 크레인

이 문제에 가장 중요한 포인트는 '외부 공기'와 '내부 빈칸'을 구분 하는 것입니다.

지게차:창고 가장 자리에 있거나, 이미 물건을 빼서 외부 공기와 연결된 길을 통해서만 물건을 뺄 수 있습니다.

크레인:위치와 상관없이 해당 종류의 모든 물건을 한 번에 뺍니다.

창고의 가장자리에 있는 물건들도 '외부에 닿아 있다'고 판단하기 쉽게, 원래 창고 주변을 .(외부 공기)로 한겹 감싸주는 작업입니다.

이유:이렇게 하면 별도의 복잡한 경계선 체크 로직 없이 "내 주변에 .이 있는가?"만으로 지게차 접근 가능 여부를 알 수 있습니다.

물건을 빼서 빈칸(0)이 생겼을 때, 이 빈칸이 외부 공기(.)와 연결되는지 실시간으로 업데이트해야 합니다.

로직:빈칸(0)이 주변에 하나라도 외부 공기(.)이 있다면, 그 빈칸도 이제 외부 공기(.)가 됩니다.

중요:공기가 한 칸 퍼지면 그 옆 칸도 연쇄적으로 퍼질 수 있으므로,더 이상 변하는게 없을 때까지 while문을 돌리는 것이 핵심입니다.

지게차:map[i][j]===target이면서 주변 4방향 중 하나라도 .이 있어야 함.

크레인:조건 없이 map[i][j]===target이면 전부 0으로 바꿈

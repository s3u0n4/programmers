# 프로그래머스 - 비밀 코드 해독

목표 :1부터 n까지의 숫자 중 5개를 고른 '비밀 코드'를 찾아야 함

모든 조합 생성(DFS)

1부터 n까지의 숫자 중 5개를 중복 없이 뽑는 과정입니다.

start변수:현재 뽑은 숫자보다 큰 숫자만 다음에 뽑도록 제한하여 [1,2,3,4,5]와 [5,4,3,2,1] 같은 중복 조합을 방지합니다.

depth === 5:5개의 숫자가 모이는 순간이 하나의 후보가 완성되는 시점입니다.

생성된 후보 조합들이 실제 문제에서 준 힌트와 일치하는지 확인합니다.

countMatch:후보 조합(arr)과 질문한 조합(q[i]) 사이에 공통된 숫자가 몇 개인가?

조건 체크: 공통 숫자 개수 === ans[i] 여부를 확인하여 , 하나라도 다르면 그 후보는 비밀 코드가 될 수 없으므로 탈락시킵니다.

재귀 호출 중에 current배열의 내용이 계속 바뀝니다. 결과를 저장할 때는 반드시 현재 상태를 복사해서 넣어야 데이터가 오염되지 않습니다.

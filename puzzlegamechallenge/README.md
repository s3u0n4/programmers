# 프로그래머스 - 퍼즐 게임 챌린지

문제 핵심 매커니즘

목표:모든 퍼즐을 limit내에 해결할 수 있는 '최소 숙련도'를 구하라.

퍼즐 해결 공식: 1.숙련도(level) >= 난이도(diff):걸리는 시간 = time_cur

    2.숙련도(level) < 난이도(diff):
       - 틀리는 횟수 = diff -level
       - 한 번 틀릴 때마다 소요 시간 = (time_cur + time_prev)
       - 마지막에 문제를 해결하는 시간 = time_cur
       - 총 소요 시간 = (time_cur + time_prev) x (diff - level) + time_cur

숙련도(level)의 범위가 1부터 100,000(혹은 그 이상)으로 매우 넓기 때문에, 하나씩 다 확인하면 시간 초과가 발생합니다.

-작동 원리: "숙련도가 X일 때 제한 시간 내에 풀 수 있는가?"라는 질문을 던지고, 결과에 따라 탐색 범위를 절반씩 줄여나갑니다.

minLevel/maxLevel 업데이트:
성공하면?"더 낮은 숙련도도 가능한가?" 확인 위해 maxLevel = mid - 1
실패하면?"더 높은 숙련도가 필요하네" 확인 위해 minLevel = mid + 1

문제에 제시된 "이전 퍼즐로 갔다오는" 복잡한 설명을 식으로 단순화하는 것이 중요합니다.

틀릴 때마다 (현재 시간 + 이전 시간)이 추가로 들고, 마지막에 무조건 현재 시간만큼 한 번 더 써서 맞춘다는 점을 코드로 녹여냈습니다.
